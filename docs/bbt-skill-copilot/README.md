# bbt-skill-copilot

Agent Skill for creating, converting, validating, running, and integrating bbt scenarios.

This package keeps the root `SKILL.md` short and moves details to focused reference files for progressive discovery.

## Files

- `SKILL.md`: metadata and routing instructions.
- `references/authoring.md`: scenario syntax, authoring rules, conversion guidance.
- `references/execution.md`: CLI usage and CI/CD guidance.
- `references/examples/`: directory for complete executable examples.
- `assets/github-actions-bbt.yml`: minimal GitHub Actions starter template.
