# Complete bbt examples

Put complete, realistic bbt scenario files in this directory.

Recommended examples:

- `minimal.md`: smallest useful scenario.
- `cli-help.md`: help and option checks.
- `file-processing.md`: scenarios creating and checking files.
- `documentation-conversion.md`: example converted from a README or user guide.
- `ci-project.md`: examples used in a CI/CD repository.

Keep examples executable and representative of real bbt usage.
